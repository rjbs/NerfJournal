# NerfJournal

NerfJournal is a bullet journal for macOS.  Its todos live on a JMAP server,
as JMAP for Tasks, and its pages and bundles in a local SQLite database.  The
model layer, shared by the app and its command-line tool, is a Swift package
called NerfCore.

- **[The manual](manual/index.md)** documents NerfCore's public interface,
  from the doc comments in its source.
- **[NerfLearning](learning/index.md)** is a curriculum that teaches Swift and
  SwiftUI by way of NerfJournal.

The source is [on GitHub](https://github.com/rjbs/nerfjournal).
